# Assignment 4: Experiment Design, Ethics & Evaluation

This folder contains the deliverables for **Assignment 4 (A04)** of the Research Methods Master's course. This assignment focused on the practical aspects of planning a study involving human participants, addressing ethical guidelines, and conducting an experimental data analysis using the course's Magic Data API.

> **Note on Ethics Documentation:** As part of Task 2, our team prepared a comprehensive **Participant Consent Form** and an **Ethics Assessment Form** (based on the Department of Informatics ethical committee guidelines). These PDF forms were submitted for grading but are not uploaded to this public repository.
